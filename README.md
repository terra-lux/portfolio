Five case studies across B2B SaaS, e-commerce, conversational AI, and B2C apps, each framed as problem → my decisions → result.

- **AI Order Agent "Dami"** — voice and chat ordering UX
- **Social login** — signup funnel redesign
- **Franchise HQ operations SaaS (외식UP HQ)** — design system, information architecture, user testing with pilot customers
- **Ledger service (차별화장부)** — 50 → 237 self-configured customers by removing setup barriers

Strengths: finding problems in data (GA4, funnel analysis) and persuading with evidence, building design standards the whole team can follow (Figma Variables → Storybook), and speaking the language of developers (HTML/CSS).
