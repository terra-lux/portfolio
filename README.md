## 구성

B2B SaaS, 이커머스, 대화형 AI, B2C 앱을 넘나드는 케이스 스터디 5개이며, 각각 문제 → 내가 내린 판단 → 결과 순서로 정리했습니다.

- **AI 오더 에이전트 '담이'** — 대화·음성 주문 UX 설계
- **소셜 로그인 도입** — 가입 퍼널 재설계와 전환율 개선
- **외식UP HQ** — 가맹본부향 운영 SaaS, 디자인 시스템·정보구조·파일럿 고객 유저테스트
- **차별화장부** — 설치 허들을 단계적으로 제거해 설정 고객 50 → 237곳
- **공비서 예약앱** — B2C 예약 서비스 0 → 1

강점은 세 가지입니다. 데이터(GA4, 퍼널 분석)로 문제를 찾고 근거로 설득하는 것, 팀이 같은 기준으로 일하도록 디자인 기준을 만드는 것(Figma Variables → Storybook), 개발 언어(HTML/CSS)로 소통하는 것입니다.

## 제작 방식

Figma 포트폴리오 덱을 바탕으로 설계하고 Claude와 함께 구현한 단일 페이지 사이트입니다. 디자인, 인터랙션, QA(라이트/다크, 한/영, 모바일)는 제가 직접 지시하고 브라우저에서 검증했습니다. 프레임워크 없이 HTML, CSS, JavaScript로만 만들었습니다.
